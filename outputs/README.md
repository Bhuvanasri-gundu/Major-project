# Verified Research Outputs & Generated Artifacts

This directory contains intermediate and final verified artifacts produced across all three phases of the research pipeline.

---

## Artifact Dictionary

### Phase 1: Empirical Literature Mining & Gap Detection
- **`mhealth_screened_corpus.csv`**: 12,642 screened mHealth records (2015–2025).
- **`document_embeddings.npy`**: 12,642 × 768 float32 SPECTER2 dense document vectors.
- **`topic_summary.csv`**: 63 official BERTopic clusters + outlier topic with top terms and paper counts.
- **`mesh_normalized.csv`**: Normalized MeSH concept associations extracted across all abstracts.
- **`concept_summary.csv`**: Master registry of 2,790 biomedical concepts.
- **`candidate_research_gaps.csv`**: Top 50 prioritized candidate research gaps scored via centroid-debiased semantic similarity and 10-year longitudinal slopes.

### Phase 2: Evidence-Grounded Hypothesis Generation & Validation
- **`faiss_index/`**: FAISS dense vector index (`IndexFlatIP`, 384 dimensions) storing 12,776 passage vectors from `sentence-transformers/all-MiniLM-L6-v2`.
- **`chunks.json`**: 12,776 abstract-level passage chunks with metadata.
- **`retrieved_gap_evidence.json`**: Top diversity-penalized retrieved passages for candidate gaps.
- **`generated_hypotheses.json`**: Structured deductive scientific propositions generated by Google Gemini.
- **`verification_results.json`**: Deterministic citation audit records confirming 100% citation traceability.
- **`nli_results.json`**: DeBERTa-v3 cross-encoder premise-to-hypothesis entailment/contradiction probabilities.
- **`judge_results.json`**: 6-dimension LLM judge ratings (1–5 scale).
- **`rule_check_results.json`**: 9 deterministic syntactic and scientific rule check outcomes.
- **`hypothesis_rankings.json`**: Multi-criteria composite ranking scores and quality tiers (`high`, `medium`, `low`).
- **`deduplication_results.json`**: Dense semantic clustering decisions.
- **`final_hypotheses.csv`**: Master export of ranked, verified scientific hypotheses.
- **`runs/`**: Complete JSON dossiers persisted from active web platform runs.

### Phase 3: Benchmarks & Empirical Evaluation
- **`phase3_evaluation_results.json`**: Full empirical evaluation dictionary (IR metrics, citation integrity, baselines, ablations).
- **`phase3_evaluation_summary.csv`**: Publication-ready benchmark comparison table.
